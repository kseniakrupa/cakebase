# CakeBase

База знаний по кондитерским изделиям: каталог тортов, рецепты, статьи, техники, видео и новости в одной поисковой выдаче.

Учебный проект по дисциплине **«Проектирование баз знаний»**  
ГрГУ имени Янки Купалы, 2026.

## Возможности

- **Каталог тортов** — 40 карточек с категориями, типом, сложностью, временем и порциями.
- **Фильтры и сортировка** — по категориям, типу, сложности, названию и времени.
- **Карточка торта** — состав, ингредиенты, рецепт, этапы, советы, связанные статьи и похожие торты.
- **Рецепты** — 40 пошаговых рецептов с граммовками и связью с тортами.
- **Статьи** — 20 материалов с рубриками, тегами и источниками.
- **Видео** — 19 тематических видеоматериалов.
- **Справочник** — 20 терминов и техник.
- **Поиск** — по слову, словосочетанию и предложению:
  - нормализация и стемминг русских словоформ;
  - Fuse.js для нечёткого поиска;
  - автокоррекция опечаток;
  - подсказки при вводе;
  - смешанная выдача по типам контента;
  - подсветка совпадений и фильтры.
- **Новости** — RSS-лента с кэшем, обновлением и резервным состоянием.
- **Онтология** — сущности, связи и правила для рекомендаций и уточнения поиска.

## Технологии

| Компонент | Технология |
|---|---|
| Frontend | React 18, Vite, JavaScript, CSS, React Router |
| Поиск | Fuse.js + собственная логика ранжирования |
| Иконки | Lucide React |
| Backend | Python, FastAPI, Uvicorn |
| RSS | feedparser, requests |
| Хранение | JSON-файлы |
| Новости | RSS + файловый кэш |

SQL-СУБД, Docker, авторизация и микросервисы не используются: для статического справочника это избыточно.

## Быстрый старт

Требуется Node.js 18+ и Python 3.10+.

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.  
Production-сборка: `npm run build`, предпросмотр: `npm run preview` (`http://localhost:4173`).  
API и документация: `http://127.0.0.1:8000`, `http://127.0.0.1:8000/docs`.

## Настройка

Frontend:

```properties
# frontend/.env
VITE_API_URL=http://127.0.0.1:8000/api
```

Backend:

```properties
# backend/app/config.py или переменные окружения
CAKEBASE_NEWS_TTL=600
CAKEBASE_NEWS_LIMIT=60
CAKEBASE_NEWS_MAX_AGE_DAYS=540
```

## API

| Метод | Описание |
|---|---|
| `GET /api/health` | Проверка работоспособности |
| `GET /api/news` | Лента новостей |
| `GET /api/news?refresh=true` | Принудительное обновление ленты |
| `GET /api/news/sources` | Список RSS-источников |

## Как пополнить базу

- Торты — `frontend/src/data/cakes.json`.
- Рецепты — `frontend/src/data/recipes.json`.
- Статьи — `frontend/src/data/articles.json`.
- Видео — `frontend/src/data/videos.json`.
- Категории — `frontend/src/data/categories.json`.
- Термины — `frontend/src/data/taxonomy.json`.
- Онтология — `frontend/src/data/knowledge/`.
- Изображения — `frontend/public/images/`; новые фото добавляйте в `CREDITS.md`.

После изменения данных выполните `npm run build`.

## Ограничения

- Контент статический и обновляется редактированием JSON.
- Поиск алгоритмический, без LLM и векторных моделей.
- Новости зависят от доступности внешних RSS-источников.
- Нет регистрации, заказов, оплаты и пользовательских аккаунтов.

## Источники данных

BBC Good Food, King Arthur Baking, Serious Eats, «Гастроном», «Повар.ру», Wikipedia, а также RSS-ленты тематических изданий.  
Изображения используются в учебных целях; авторы и лицензии указаны в `frontend/public/images/CREDITS.md`.
